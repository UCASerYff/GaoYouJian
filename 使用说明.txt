搞邮件 V1.06
邮箱 · 身份 · 平台

适用系统：Apple Silicon Mac，macOS 14 或更新版本。
本版为本机个人使用的原生客户端，采用本地签名；未做 Apple 公证。

开始使用
设置入口位于屏幕顶部“搞邮件 > 设置…”菜单，快捷键为 ⌘,，打开独立的“模块设置 / 外观 / 数据”窗口。窗口最上方显示软件名称及版本号。⌃⌘S 显示或隐藏侧栏，⌘F 搜索，⌘N 写邮件，⌘R 同步邮箱。
1. 打开“邮箱账户”添加邮箱，选择学校、工作、生活，或在左侧新增自定义身份。
2. 可以先仅登记邮箱和关联平台。开启“启用收发”后，填写 IMAP 和 SMTP、用户名、TLS 与客户端授权码，并点击检测连接。
3. QQ、163、vip.163 等需要在服务商网页开启客户端访问，使用授权码。iCloud 等使用 App 专用密码。
4. Gmail、Outlook / Microsoft 365 使用 OAuth。首次需在设置填入合法注册的客户端 ID，再在邮箱编辑页授权。详情见 Docs/OAuthSetup.txt。Google 账户允许时，也可手动选专用应用密码。
5. 公司 .cn、学校 .edu / .edu.cn 的域名后缀不代表协议。可以参考 iPhone 邮件账户中的主机名、端口和账户类型；只有 Exchange ActiveSync 的账户需向管理员确认 IMAP / SMTP 和第三方应用授权是否可用。

身份和平台
每个邮箱可指定一个自定义身份，添加标签、签名和别名。
“关联平台”可手动登记网站、App、实际绑定的邮箱、账号、登录方式、用途、状态和备注；修改关联邮箱与状态会留下历史。
登记关联不代表已经访问平台核验，更改资料也不会自动修改网站上的邮箱。实际换绑仍需到平台操作，然后在本软件更新记录。
移除邮箱会保留平台记录和草稿文字，并解除邮箱关联。

悬浮窗
启用时默认只显示屏幕边缘的一条竖线；从主窗口工具栏、菜单栏信封、“显示”菜单或 ⌃⌘M 可以启用或隐藏。
鼠标移入竖线后展开，移出卡片后快速收起，点击其他位置立即收起。判定范围跟随实际可见卡片，不把窗外或透明圆角算作内部。隐藏形态的实际窗口为 20×104，竖线为 6×88，不用透明大窗口遮挡其他软件。
悬浮窗顶部不显示软件图标、名称、标题、版本号或管理按钮，只保留一小段空白拖动区域。拖动顶部空白或隐藏竖线可调整边缘和高度；松手后吸附最近的左右边缘并保存位置。再次展开及重启沿用保存的位置。
V1.05 取消图钉、关闭、选项、缩小等顶部按钮，以及固定展开和紧凑模式。旧版固定 / 紧凑设置不会再生效，不影响自动收起。Esc 可立即收起；要完全关闭竖线入口，可从菜单栏或“显示”菜单隐藏悬浮窗，或关闭外观设置中的显示开关。
显示状态、边缘、显示器、位置和透明度会自动保存；拔掉显示器后重新落在可用屏幕内。只在本悬浮窗的拖动、按住和邮箱菜单操作期间保护交互，不因其他窗口的鼠标按下或无关菜单保持展开。
V1.06 卡片随真实内容调整高度，压缩顶部及底部留白；长邮件预览或小屏幕可滚动。拖动期间暂缓尺寸重排，松手后应用新内容高度。
展开卡片可选择全部邮箱或单个邮箱，查看缓存未读数、启用 / 仅登记数量和同步状态。计数只包含本机已缓存的收件箱未读邮件，并非服务商全部邮件的未读总数。
默认隐藏发件人和主题。在“设置 > 外观 > 悬浮窗”开启邮件预览，可显示最近三封缓存未读邮件；展开窗口、切换邮箱和预览本身不会标为已读。
点击预览打开主窗口的对应邮件；收件箱、同步和写信按钮作用于当前选择的邮箱。同步只对已启用收发的邮箱执行；关闭主窗口后应用仍可同步和使用悬浮窗。
打开收件箱、写信或设置时收起到边缘，保留再次展开的入口。菜单栏信封还可显示 / 隐藏悬浮窗、打开收件箱、写邮件、打开设置及正常退出。
外观设置可调整 65%～100% 透明度并重置位置。悬浮窗是应用内原生窗口，无小组件扩展。

收发邮件
统一收件箱可按身份、邮箱筛选和搜索。每个文件夹默认同步最近 80 封，可在设置调整；正文和附件在打开时读取。搜索覆盖已同步邮件和已缓存正文，并非整个服务器邮箱。
可回复、回复全部、转发正文、添加附件、抄送、密送、标记已读、星标和移动文件夹。
转发正文不会自动转发附件，请自行添加需要的文件。附件总大小需低于 24 MB，服务商可能有更低限制。
发件别名必须已经在邮箱服务商一侧获得发送权限；本软件的别名登记本身不会授予权限。
SMTP 接受只表示服务商已接收，不保证收件人最终投递成功。连接中断如提示“发送结果不确定”，应先核查服务商已发送记录，避免重复发送。本版没有自动重试发送。
每次发送成功会保留“本机发送记录”，在收件箱选择具体邮箱后可切换查看。此记录存于邮件缓存中，资料备份不包含它。服务商的已发送文件夹是否自动保存取决于服务商；自建邮箱可在邮箱编辑页指定 IMAP 已发送文件夹。服务商已经自动保存时请留空，避免双份。
正文默认纯文本；原始 HTML 查看禁止脚本、表单及外部资源加载。外部链接交给系统浏览器打开。
关闭主窗口后 App 继续运行并同步；Cmd+Q 完全退出。编辑器自动保存草稿，退出时再次保存。没有启用收发的邮箱不会产生网络请求。

数据与备份
本地数据：~/Library/Application Support/GaoSeries/GaoYouJian
账户资料、平台、身份和草稿保存在 Library.json；邮件缓存和本机发送记录保存在 MailCache.json。
密码、专用授权码与 OAuth 令牌保存在 macOS 钥匙串，不写入安装包或资料备份。资料和邮件缓存是本机文件，依赖 macOS 账户权限及系统磁盘保护；本版没有额外数据库加密。
设置中可导出或恢复 JSON 资料备份，导入导出平台 CSV。恢复会替换当前资料，事先保留恢复前副本，并将邮箱设为仅登记，需重新检查授权。
资料备份不含密码、令牌、邮件缓存、本机发送记录或附件内容。草稿附件仅记录原文件路径，原文件移动后需重新添加。
CSV 以 UTF-8 BOM 导出。为防止表格公式执行，公式起始字符前会添加单引号；重新导入时保留该安全前缀。平台 CSV 不包含完整历史，完整历史请使用 JSON 资料备份。
本地资料损坏时会停止写入，避免空资料覆盖原文件。请从有效备份恢复。

版本与更新
首次 V1.00，以后每个正式更新增加 0.01（V1.01、V1.02……）。
安装脚本会验证安装包、正常退出旧版、替换应用，并在新版启动成功后删除旧程序及历史安装包。构建中间文件使用临时目录并自动清理。
用户邮箱、平台记录、草稿与钥匙串属于用户数据，升级保留。不会以清理旧版本为由删除资料。

本版范围
提供 IMAP / SMTP 和 Google / Microsoft OAuth 接入。Proton Mail 不在范围内。
仅支持所选账号允许的协议和权限；尚未用用户真实邮箱执行收发验收。
不包含 POP3、Exchange ActiveSync / Graph 邮件后端、自动扫描所有注册平台、跨设备同步、后台云端发送、日历或联系人同步。
